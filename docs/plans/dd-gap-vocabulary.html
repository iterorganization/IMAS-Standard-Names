§1 — Why this release exists

imas-codex composes a standard name for every DD quantity. After its full DD run, 86 sources could not be named because the grammar has no word for something they measure: a power convertor, a slit, a stress tensor, the tritium decay that seeds runaway electrons. imas-codex classified every missing token as add, reject (an existing spelling already says it) or decompose (existing tokens already compose it). That worklist is /home/ITER/mcintos/Code/imas-codex/docs/evidence/fragments/sn-integrity-backlog/sib-vocab-worklist.json, merged in imas-codex 5137eaf7d and read against this repository's tag v0.10.1.

The lead ruled on it on 2026-11-09:

  • Composites are split into their parts. The coil equipment is poloidal_field_coil, never a "circuit". Power equipment is power_convertor, never a "power supply".
  • The clean physics additions and the eleven rejections are accepted as listed.
  • The argmax operator and the threshold_crossing state are accepted now, with the grammar machinery they need.
  • Six doubtful additions are reworked once more before any of them enters the grammar: species (subject), breakdown_candidate_grid_point, breakdown_candidate_field_line, current_alignment, plateau and green_function.

This repository owns the vocabulary and its release; imas-codex owns the pin bump, the graph grammar snapshot and the rerun of the sources, under its own plan sn-integrity-backlog §51.

§2 — The accepted vocabulary enters the grammar

Add these 36 tokens, in the segment the worklist assigns and with its one-sentence definition, by editing the vocabulary YAMLs and grammar/specification.yml and regenerating with build-grammar. Never hand-edit the generated files.

source (qualifier), horizontal (component), pipe, ion_source, optical_fibre, power_convertor, slit, thermal_shield (devices), image_surface, magnetic_field_line, pre_sawtooth_crash, threshold_crossing (positions), arc_of_circle, oblique, thick_line (geometry representations), image, grid (geometry), ballooning_parameter, delta_prime, stress (physical bases), helical, ripple, sine, cosine, chemical, bounce, compressive, second_inclination, rotational, tangency (qualifiers), argmax (operator), tritium_decay, fragmentation, sublimation (processes), lithium_6 (subject), side (zone).

argmax returns the coordinate at which its operand profile is maximal, so the name it forms has the unit of that coordinate, not of the operand. threshold_crossing names the event at which an observable first crosses a stated threshold. Both need their unit and rendering rules carried by the grammar rather than by one name.

Done when:

  • every one of the 36 tokens is present in its declared segment with the worklist's definition, and build-grammar leaves the generated files without drift;
  • a test parses and round-trips one representative name per token, taken from the worklist row that needs it, and a planted removal of any one token fails that test;
  • poloidal_field_circuit, power_supply and the other ten rejected spellings stay unparseable as new tokens, by test;
  • a name formed with argmax carries the coordinate's unit, and one formed with threshold_crossing renders and parses canonically, each by test;
  • the grammar test suite adds no failure id against the stated base.

§3 — The six doubtful additions are reworked

The lead judged six proposed tokens too generic or too composite. Each is reworked against the DD documentation of the sources that need it. A generic species subject is replaced by the named pellet species already in the vocabulary. The two breakdown_candidate_* words are split into their parts. Each of current_alignment, plateau and green_function is expressed with existing tokens or as one named physical quantity whose definition stands on its own.

Done when: docs/evidence/fragments/dd-gap-vocabulary/doubtful-rework.json holds one row per doubtful token with every DD source path it blocks, the reworked spelling or parts, the existing token each part reuses, and the DD documentation that justifies it; any genuinely new token is listed separately with its definition for the lead's ruling; doubtful-rework.html beside it summarises the result. No grammar file changes in this section.

§4 — The grammar is released and handed to imas-codex

Once §2 lands, cut a minor release from main with the release CLI. The CLI refuses a detached worktree, so the coordinator cuts it from the main checkout after CI is green on upstream. imas-codex then bumps both pins in its pyproject.toml and syncs its graph grammar snapshot under its own plan.

Done when: a tag above v0.10.1 carrying §2 is pushed to upstream, its publish workflow is green, and PyPI reports that version as latest.
