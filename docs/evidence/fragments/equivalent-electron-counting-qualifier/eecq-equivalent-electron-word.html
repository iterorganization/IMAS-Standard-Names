Equivalent-electron counting vocabulary

Registered equivalent_electron in grammar/vocabularies/qualifiers.yml and regenerated the public Qualifier.EQUIVALENT_ELECTRON member with the repository generator. Its presentation group is normalized, which includes unit conventions. The qualifier uses the existing kind-forming composition and has no base restriction.

The single definition is held in grammar/vocabularies/conventions/concepts.yml: one unit per electron carried by each injected atom or molecule, using electron content rather than instantaneous ionization state. Count and source-rate names select that same concept.
